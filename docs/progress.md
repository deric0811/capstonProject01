## 3. 예측 문제와 평가 설계 (`spec.md` §1~5)
- **문제**: 거래일 t의 공표가로 **3·7거래일 후** 도매 평균가와 등락률, 방향(상승/보합/하락, δ = 3%)을 예측한다.
- **지표**
  - 가격: MAE(주), MAPE, 직전가 대비 상대 MAE
  - 방향: 상승/하락 적중률(주. 실제 |r| > 3%인 날만 셈), 3분류 적중률(보조)
- **비교 대상**: 기준선 B1 직전가와 B2 최근 5거래일 평균. 후보는 LightGBM과 Chronos-2.
- **검증**
  - 시간순 walk-forward: 학습 ~2019, 튜닝 2020~2022, 테스트 2023~
  - 월 1회 재학습
  - 급등 구간 2023-09 ~ 2024-12는 따로 보고한다.
- **선택 규칙** (결과를 보기 전에 고정)
  - 상대 MAE < 1인 모델 중 MAE가 가장 낮은 모델을 고른다.
  - 단, 상승/하락 적중률이 B2보다 낮은 모델은 뺀다.
  - 남는 모델이 없으면 B1을 채택한다.
  - 기간(3·7거래일)별로 따로 적용한다.
- **매입 시뮬레이션** (보고만 하고 선택 규칙에는 쓰지 않는다): 기간 안에 1단위를 산다고 가정한다. A는 항상 t+1, B는 상승(예측 등락률 > +3%) 예측이면 t+1, 아니면 t+h에 산다. 총 매입비 차이를 전체·급등 구간으로 보고한다.

- **2단계 결과** (`stage2-backtest.md`, 전체 테스트 구간, 절감액은 A − B)

| h | 모델 | MAE(원) | 상대 MAE | 상승/하락 적중률 | 절감액 |
|---|---|---|---|---|---|
| 3 | B1 | 1,553.5 | 1.0000 | 0.0% | −10,400원 |
| 3 | LightGBM full (선택) | 1,415.6 | 0.9112 | 67.6% | 106,900원 (0.55%) |
| 7 | B1 | 2,901.6 | 1.0000 | 0.0% | −38,020원 |
| 7 | LightGBM full (선택) | 2,670.2 | 0.9203 | 71.1% | 439,120원 (2.26%) |

## 4. 주요 결정과 이유 (전체는 `docs/decisions.md`)
1. **기간을 거래일 기준 3일로**: 주말과 연휴에는 공표가가 없다. 화면에는 예상 실제 날짜를 함께 표시한다.
2. **평가 규칙을 결과보다 먼저 고정**: 수치를 맞추려고 평가 방식을 바꾸지 않기 위해서다(intent Done criteria).
3. **FastAPI + PostgreSQL**: 마감이 짧아 자동 API 문서가 필요했다. DB 선택은 결과에 미치는 영향이 작다.
4. **LLM은 설명만, 숫자 근거 검사**: 가격 예측은 ML이 한다. LLM 출력의 숫자가 입력에 없으면 템플릿 문장으로 대체한다.
5. **공휴일은 `holidays` 라이브러리(KR)**: API 키가 필요 없고 외부 의존이 줄어든다. 대신 대체·임시공휴일이 빠질 수 있다.
