## 2026-11-05: 매입 시뮬레이션을 보고 지표로 추가 (t+1 기준)
- 결정: 기간 안에 반드시 1단위를 산다고 가정한다. 전략 A는 항상 t+1, 전략 B는 상승(예측 등락률 > +3%) 예측이면 t+1, 아니면 t+h에 산다. 총 매입비 차이(원, %)를 전체·급등 구간으로 보고하고, 모든 모델에 같은 규칙을 쓴다. 보고만 하고 모델 선택에는 쓰지 않는다.
- 대안
  - y(t) 매입 또는 y(t)와 t+1 병행: y(t)는 예측 시점에 이미 경매가 끝난 가격이라 실제로 살 수 없고 B에 유리한 편향이 생겨 넣지 않는다.
  - 상승을 예측 등락률 > 0으로 정의: 대시보드의 방향 표시(δ = 3%)와 달라지고, spec이 3%를 매입 판단에 의미 있는 차이로 정해 두었으므로 쓰지 않는다.
  - 시뮬레이션을 선택 규칙에 포함: 선택 규칙은 결과를 보기 전에 이미 고정했으므로 바꾸지 않는다.
- 이유: 1순위 사용자의 판단은 매입 시점이므로 오차보다 비용으로 보여주는 편이 직접적이다.
- 한계: 기간이 겹치는 매입이고, 수수료·보관비·품질 변화를 넣지 않았다. 실제 비용 절감액이 아니라 규칙 간 비교다.

## 2026-11-09: B3 추세 규칙, 오라클 시뮬레이션, h = 21 사전 등록
- 결정
  - B3 추세 규칙: 방향 지표와 매입 시뮬레이션에만 쓰는 기준선으로 두고, 모든 결과표에 B1·B2와 함께 싣는다. 시뮬레이션의 상승은 y(t) > 최근 5거래일 평균이다(δ 없음).
  - 오라클: h = 3, 7 매입 시뮬레이션의 상한으로 보고한다(최적·규칙 두 가지).
  - h = 21: 같은 walk-forward·튜닝·선택 규칙으로 평가하고, 시뮬레이션은 하지 않는다. `predict`로 저장하지 않는다.
  - h = 21 DM 검정: B1 대비, 본페로니 α = 0.025(전체·급등 2개). 분산이 0 이하면 Bartlett 가중으로 바꾼다.
  - 기존 선택 규칙과 2단계 결과는 바꾸지 않는다.
- 대안: B3 상승에 δ = 3% 적용 / 오라클을 한 가지만 보고 / 전체 구간만 주 검정(α = 0.05)
- 이유
  - 사후 분석에서 h = 3 방향 적중의 대부분이 단순 추세 규칙으로 설명됐다. 앞으로는 모델의 방향 성능을 이 규칙과 나란히 봐야 한다.
  - 절감액이 큰지 작은지 판단하려면 상한이 필요하다. 같은 규칙에 실제값을 넣는 오라클은 엄밀한 상한이 아니므로 최적값도 함께 낸다.
  - 유통업자의 월 단위 계획에 맞는 기간도 확인한다.
- 사전 등록 범위: h = 3, 7의 B3 방향 적중률은 사후 분석에서 이미 봤으므로 사전 등록이 아니다. 새로 등록하는 것은 B3 시뮬레이션, 오라클, h = 21 전체다.
- 데이터 끝: 2단계와 같은 `--to 2026-11-04`. h = 3, 7 표의 예측 시점이 기존과 같아진다.
