# EDA: KAMIS 토마토 가격 (모델링 전 점검)

점검일: 2026-10-31 · 입력: `data/raw/` (목록과 해시는 `data-manifest.md`) · 재현: `.venv/bin/python scripts/eda_kamis.py`

## 1. 단위
- 도매는 1996~2026 전 기간 `토마토(5kg)`, 소매는 전 기간 `토마토(1kg)`으로, 등급 04·05 모두 **바뀐 시점이 없다**.
- 단위는 시장 행의 `kindname`으로 확인했다. 16·17번 API 응답에는 unit 필드가 없고, `평균` 행은 kindname이 비어 있다.

## 2. 도매 `평균` 행의 정의
- 1번 API 공표가(당일 `dpr1`, 상품)와 5개 날짜를 대조했고 **모두 일치**했다. 기존에 대조한 2026-10-28을 더하면 6/6이다.

| 날짜 | CSV `평균` | API 공표가 |
|---|---|---|
| 2002-11-01 | 10,667 | 10,667 |
| 2007-04-18 | 13,200 | 13,200 |
| 2012-02-14 | 19,600 | 19,600 |
| 2016-12-30 | 19,800 | 19,800 |
| 2021-11-24 | 18,200 | 18,200 |

- 2002-11 이후 `평균`은 그날 가격이 있는 시장들의 단순 평균(반올림)과 6,018일 중 6,017일 일치했다.
- 따라서 **`평균` = 그날 가격이 있는 시장의 단순 평균 = KAMIS 공표 도매가**이다.

## 3. 그래프 (2002-11 이후, 도매 평균, 상품)
- `eda/wholesale_daily.png`: 일별 가격
- `eda/wholesale_monthly.png`: 월별 분포
- **계절성이 뚜렷하다.** 월 중앙값이 6월에 약 8,500원으로 가장 낮고, 2~3월과 9~10월에 약 16,000원으로 높다. 9~10월은 분산도 가장 크다.
- 2020년 이후 가격 수준과 변동폭이 커졌다. 최고치는 2024-10-14의 56,300원이다. 5개 시장이 모두 52,000~59,000원이었고 여러 날 이어졌으므로 입력 오류가 아니라 실제 급등으로 보인다.

## 4. 결측 (2002-11 이후)
- 거래일 중 `평균` 행이 빠진 날: 도매·소매 모두 **0일**.
- 최장 연속 무거래: **10일** (2017-09-30 ~ 2017-10-09, 도매·소매 동일).
- **시장 단위 결측:** 가격이 `-`인 행이 있다.
  - 도매: 부산 486행(주로 2024~2025), 광주 518행(주로 2019~2020), 대구 2행, 대전 4행
  - 소매: 지점별로 수백~수천 행
  - `평균`은 그날 있는 시장만으로 계산되므로, 시장이 빠진 기간에는 평균의 구성이 달라진다.
